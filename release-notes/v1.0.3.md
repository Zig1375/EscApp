Magic Kettle 1.0.3: double-clicking a game's `.exe` opens it in Magic Kettle right after installing, even on a Mac
where another app had `.exe` files.

## New in this version

- **Magic Kettle takes `.exe` and `.msi` files on its first launch.** The first screen says to find a game and
  double-click its `.exe`, but on a Mac that had Whisky, CrossOver or EscApp, Finder kept opening `.exe` files with
  that app: macOS keeps the app a person picked before, and Magic Kettle only asked to be the default. Now the first
  launch makes Magic Kettle the default app for both, without a dialog, so the next double-click opens the game in
  Magic Kettle.
- **`.msi` installers are recognised on Macs with Whisky.** Whisky declares `.msi` as a type of its own
  (`com.microsoft.msi-installer`); Magic Kettle now declares and takes that type too.

## What to watch for

- This happens once. If you later pick another app for `.exe` files in Finder (Get Info › Open with › Change All),
  Magic Kettle leaves that choice alone; Settings › General › "Open .exe files with a double-click" takes them back.
- This version can't update itself: install 1.0.4 or later by hand once.
