Magic Kettle 1.0.5: every release now says what changed, on GitHub and in the update window.

## New in this version

- **Detailed release notes for every release.** Each version's page on GitHub describes what changed for players
  and what to watch for, and the window that offers an update shows the same text before you install it. Before,
  a release had only a link to the list of commits. The notes of 1.0.2, 1.0.3 and 1.0.4 are filled in too.
- **No release without notes.** The release job stops before building when a version has no notes, so a version
  can't reach players without saying what it brings.

## What to watch for

- Nothing changes in how games run in this version.
