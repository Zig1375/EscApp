Magic Kettle 1.0.4: Magic Kettle now updates itself. Install this version by hand once; from now on new versions
come to you.

## New in this version

- **Magic Kettle checks for a new version every day** and offers to install it, showing what changed. Install
  Update downloads it, checks it and relaunches Magic Kettle in the new version; Skip This Version and Remind Me
  Later leave things as they are.
- **"Check for Updates" checks the app too.** The button in Settings › Components, and Check for Updates… in the
  Magic Kettle menu, used to look only at Wine, DXVK and DXMT, so pressing it never brought a new Magic Kettle. It
  now checks the app and its components together, and says when you already have the newest version.
- **Updates are signed.** Each release is signed with Magic Kettle's own key in the release job, and the app installs
  only an update that carries that signature. Updates come from this repository's Releases, like the downloads.
- **Updates skip the "can't verify" step.** An update installed by Magic Kettle opens without the System Settings
  › Privacy & Security step a downloaded zip needs.

## What to watch for

- 1.0.3 and earlier can't update themselves: download this version from Releases once.
- "Update components automatically" in Settings › General applies to Wine, DXVK and DXMT only; the app's own daily
  check is always on and asks before installing anything.
- The app now loads its update library (Sparkle.framework) with library validation turned off, because releases are
  signed without an Apple developer certificate.
