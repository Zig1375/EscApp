Magic Kettle 1.0.2: the app has its new name and icon. This is the oldest Magic Kettle release still published, so
below is also everything Magic Kettle does.

## New in this version

- **EscApp is now Magic Kettle.** The app is "Magic Kettle.app", its menus, windows, site and repositories say
  Magic Kettle, and its icon is a kettle shaped like a game controller, with sparkles. The library's header reads
  "Magic Kettle — Just open it and play" in each of the app's nine languages (the tagline is dropped when the window
  is too narrow for it).
- **A fresh start.** Magic Kettle keeps its games, settings and downloads in `~/Library/Application Support/MagicKettle`
  and marks a game's folder with a `.magickettle` file. It doesn't read EscApp's folder or `.escapp` files: open each
  game once more and Magic Kettle sets it up again, and remove EscApp's folder when you no longer need it.
- **The app shows its icon.** The release is built with Xcode 26, which understands the Icon Composer icon; an
  earlier build of 1.0.2 showed a blank icon and was withdrawn.

## Everything Magic Kettle does

### Games

- **Double-click a game's `.exe` and play.** Magic Kettle reads the program, works out what it needs and picks how
  to draw it on Metal: DXMT or DXVK for DirectX 10 and 11, WineD3D for DirectX 9 and older. If the first way fails,
  the first launch tries the next one while a cover hides the game's window, then remembers what worked; later
  launches start straight away.
- **DirectX 12 games run on Apple's D3DMetal**, which you add from Apple's "Evaluation environment for Windows
  games" in Settings › DirectX 12. Magic Kettle never ships or downloads it.
- **Steam and the Epic Games Store** install with one button. Their games install, sign in and start through the
  store as on Windows, and appear in the library with their covers.
- **Installers and disc images** (ISO, BIN/CUE) work, including old games that ask for their CD.
- **Unity, RPG Maker XP/VX/VX Ace, NW.js and Electron games.** RPG Maker's Run Time Package and the Visual C++ and
  .NET runtimes a game needs are installed from their publishers only when a game needs them.
- **Japanese games** start with Japanese settings and fonts.
- **Small and old games are made bigger** smoothly, without changing the Mac's display, and fixed-size windows can be
  stretched by their corner. Retina is used when the game says it supports it.
- **Settings known for particular games** come from MagicKettle-Games and are fetched daily.

### Your Mac

- **One profile for every game**, so saves and settings stay in one place (Settings › Saves).
- **Nothing about you or your games is sent anywhere.** Every download of something Magic Kettle runs is checked
  against a pinned SHA-256.
- **Wine, DXVK and DXMT update themselves**, daily, unless you turn off "Update components automatically" in
  Settings › General. Magic Kettle runs games on its own build of Wine 11.20 from MagicKettle-Runtime.
- **Nine languages**: English, German, Spanish, French, Italian, Japanese, Korean, Russian and Simplified Chinese.

## What to watch for

- Games added to EscApp aren't in Magic Kettle's library until they are opened again.
- Magic Kettle isn't notarized by Apple: the first time, open it from System Settings › Privacy & Security
  (see Download below).
- This version can't update itself: install 1.0.4 or later by hand once.
