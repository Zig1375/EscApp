Magic Kettle 1.0.6: games on several CDs install to the end — the next disc goes in while the installer waits.

## New in this version

- **Installing a game from several disc images works.** When a game's installer asks for its next CD ("Please
  insert disc 2"), the install window now says so, quotes the installer's own message and offers **Choose Disc
  Image…**. Pick that disc's image, then press Retry or OK in the installer's window, and the install goes on —
  disc 3 and later the same way. Before, only the first image could be in the drive: the installer kept asking for
  disc 2 and the install could never finish.
- **Change Disc… for installers that ask in their own window.** Some installers draw their own "insert the next
  disc" screen, which Magic Kettle can't read. While any install from a disc image runs, the install window has a
  **Change Disc…** button for exactly that case.
- **The disc's label changes with the disc.** Many installers check the label of the disc in the drive, not only
  its files, to tell which CD is in. Wine kept the label of the first disc for as long as the installer ran, so even
  a correctly swapped disc 2 was still "disc 1" to the installer. Magic Kettle now changes the disc from inside
  Windows itself, the way Windows' own drive settings do, so the installer reads the new label at once.

## What to watch for

- Every disc used during the install stays attached until the install window closes: an installer that started
  from disc 1 may still be running from it. They are all ejected together at the end.
- If the game itself checks for its CD later, the first disc is the one kept for it ("Keep the disc in after
  installing"). A game that wants another disc to play asks for it, and **Choose Disc Image…** on that message
  switches it, as before.
- If the installer asks for the next disc and nothing happens after you choose its image, press Retry in the
  installer's window: some installers look at the drive only when asked to.
